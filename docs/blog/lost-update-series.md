# Lost Update 시리즈 계획

## 한 줄 정의
같은 행을 **락 없이 읽고 → 애플리케이션에서 계산하고 → 계산한 상수 값으로 덮어쓰면**,
그 사이 다른 트랜잭션이 바꾼 값이 사라진다.

```
T1: SELECT balance → 1,000,000      T2: SELECT balance → 1,000,000
T1: UPDATE SET balance = 1,010,000  → 커밋
                                    T2: UPDATE SET balance = 990,000 → 커밋  ← T1의 입금이 사라짐
```

MySQL REPEATABLE READ에서도 막히지 않는다. 일반 SELECT는 락 없는 **스냅샷 읽기**이기 때문이다.

## 재현 목록

| 구분 | # | 상황 | 상태 |
|---|---|---|---|
| A. 읽기-계산-쓰기 | 1 | 입금·차감 동시, JPA 변경 감지 | ✅ 재현 (`docs/experiments/01-lost-update.md`) |
| | 2 | 한쪽 경로만 고침: 입금은 원자적 UPDATE, 차감은 여전히 변경 감지 → 차감이 옛 잔액으로 덮어씀 | |
| | 3 | 긴 배치: 차감 배치가 지갑을 읽고 한참 뒤 저장, 그 사이 들어온 입금이 사라짐 | |
| C. 락 범위 | 8 | 분산 락(Redisson)을 트랜잭션 **안에서** 해제 → 커밋 전에 다음 요청이 옛 값을 읽음 | |
| D. 잔액 외 컬럼 | 9 | `last_ledger_id` 역행: 잔액은 맞지만 원장 ID 발급과 지갑 갱신 순서가 뒤집혀 더 작은 ID로 덮어써짐 | v2 구현 때 확인 |
| E. 격리 수준 | 10 | 1번을 READ COMMITTED / SERIALIZABLE에서 실행 (SERIALIZABLE은 Lost Update 대신 데드락 예상) | |
| | 11 | (선택) PostgreSQL REPEATABLE READ: 덮어쓰지 않고 에러로 실패 | |
| 번외 | — | Write Skew: 서로 다른 행을 각자 확인하고 써서 합산 규칙이 깨짐 | 다른 동시성 문제 편으로 |

다루지 않기로 한 것:
- B. JPA 함정 (벌크 UPDATE 후 옛 엔티티가 덮어씀, 전체 컬럼 UPDATE). 단 4번(벌크 UPDATE 후 덮어씀)은 v2 구현 중에 마주치면 짚는다.
- `synchronized` 관련 (실무에서 분산 환경 동시성 해결에 쓰지 않음). 락 범위 문제는 8번으로 다룬다.

## 대응 방식 (코드에 공존, `DebitMethod`로 선택)

| 버전 | 방식 | 핵심 | 예상 비용 |
|---|---|---|---|
| v1 | 변경 감지 | 문제 재현용 (당시 구조) | — |
| v2 | 원자적 UPDATE | `SET balance = balance - ? WHERE balance >= ?`. 계산을 DB가 최신 값으로 함 | 가장 쌈, 대신 엔티티를 안 씀 |
| v3 | 비관적 락 | `SELECT ... FOR UPDATE` 후 변경 감지 | 락 대기, 핫 로우에서 TPS 하락 |
| v4 | 낙관적 락 + 재시도 | `@Version`, 충돌 시 예외 → 재시도 | 충돌 많으면 재시도 폭증 |
| — | 분산 락 | Redis 락, 트랜잭션 바깥에서 획득·해제 | Redis 의존, 경계 실수(8번) |
| — | CHECK (balance >= 0) | 최종 안전망 | Lost Update 자체는 못 막음 |

## 배운 개념
- **스냅샷 읽기 vs 현재 읽기:** 일반 SELECT는 트랜잭션 시작 시점 스냅샷(락 없음), UPDATE·`FOR UPDATE`는 최신 커밋 값을 락 걸고 읽음
- **원자적 UPDATE:** 재고·쿠폰·포인트처럼 숫자를 늘리고 줄이는 곳에서 흔한 방식. JPA 스타일은 아니라 `@Query`로 쓴다
- **락 범위 > 트랜잭션 범위:** 애플리케이션 락은 커밋이 끝난 뒤에 풀어야 한다

## 정직성 메모
운영 중 Lost Update로 돈이 사라진 사고를 겪은 게 아니라면, 제목과 본문은 "운영 구조를 재현해서 확인했다"로 쓴다.
(기존 가제 "입금 5만 원이 사라졌다"는 재현임이 드러나게 고칠 것)
